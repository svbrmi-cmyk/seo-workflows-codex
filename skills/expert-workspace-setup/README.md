# Рабочее пространство эксперта и автора (Контент-завод)

Набор, который превращает любую папку на компьютере в персональную фабрику контента и запусков. Ты отвечаешь на 3 коротких вопроса — система сама разворачивает папки, создаёт систему локальной памяти и настраивает 7 инструментов под твои задачи.

**Без облачных подписок, без Obsidian, без сложных интеграций.** Только локальные файлы, которые моментально считывает ИИ-агент.

---

## Что внутри

```text
expert-workspace-setup/
├── SKILL.md                 ← логика развертывания, экспресс-интервью и онбординг
├── README.md                ← эта инструкция
└── references/              ← шаблоны файлов памяти, правил и настроек
```

---

## Возможности харнеса

1. **Экономия токенов:** Файлы читаются диапазоном. Для поиска цитат и старых материалов используется субагент `scout`, который возвращает только краткую выжимку в 10–15 строк, не забивая контекстное окно.
2. **Самообучение (Self-Learning Loop):** Все замечания и новые правила автора агент сразу сохраняет в блоке правил в `AGENTS.md`. Стратегические решения сохраняются в `wiki/decisions.md`. Воркспейс накапливает опыт и адаптируется под автора.
3. **Безопасность:** Ключи и токены блокируются правилами в `.claude/settings.json`, временные файлы автоматически очищаются хуком при завершении сессии.

## Как запустить за 1 минуту

### Вариант 1 — Antigravity / Gemini CLI
1. Открой папку проекта в Antigravity.
2. Напиши агенту:
   ```text
   /expert-setup
   ```
   или просто: «*настрой рабочее пространство эксперта*».

### Вариант 2 — Claude Code
1. Открой папку проекта в Claude Code.
2. Введи команду:
   ```text
   /expert-setup
   ```

Ответь на 3 коротких вопроса. В конце сессии всё пространство будет готово к работе, а агент сразу предложит первый шаг под твою задачу.
