# Паспорт авторского стиля

Этот файл задаёт правила голоса автора для всех создаваемых материалов (постов, тредов, сценариев видео, статей).

## Статус паспорта
- Статус: [активен / ожидает снятия по архиву постов]
- Дата последнего обновления: [дата]

## Быстрые ориентиры стиля
- Тональность: [прямой диалог / экспертная аналитика / спокойная уверенность]
- Ритм предложений: [короткие тезисы 7–12 слов / чередование коротких и средних]
- Любимые выражения и обороты: [характерные фразы автора]
- Эмодзи-профиль: [только функциональные стрелки и маркеры / без смайлов]

## Как снять точный цифровой отпечаток
Для расчёта точных биометрических метрик (длина предложений, плотность знаков препинания, n-граммы, характерные цитаты) запусти команду:
```text
/style-passport
```
и укажи путь к файлу экспорта Telegram-канала (`result.json`) или текстам своих лучших постов. Скилл автоматически сформирует детальный паспорт стиля по 16 осям.
