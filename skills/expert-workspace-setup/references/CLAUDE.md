# CLAUDE.md

Главная инструкция этого рабочего пространства — в **AGENTS.md**. Прочитай его первым.

Этот файл служит точкой входа для автоматического подхвата инструкций в Claude Code. Все содержательные данные, регламенты и карта памяти хранятся в `AGENTS.md`, `context/` и `wiki/`.

## Быстрые правила
- Временные файлы сохраняй только в `scratch/` (папка очищается автоматически).
- Перед выполнением задачи читай карту памяти в `AGENTS.md`, не сканируй весь репозиторий.
- Перед созданием текстов читай `context/style-passport.md` и `context/taboo.md`.
- В конце сессии фиксируй результат в `sessions/` и `wiki/log.md`.
- Секреты и ключи сохраняй только в `.env`.
