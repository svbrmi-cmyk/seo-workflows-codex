# Доказательная модель

## Иерархия источников

Выбирать источник по типу утверждения:

1. Официальные страницы, документы, тарифы, условия, сертификаты и реестры — для фактов о предложении и правилах.
2. Независимые авторитетные отраслевые и деловые источники — для рыночного контекста и внешней проверки.
3. Официальные сайты конкурентов — для сопоставления предложения.
4. Независимые платформы отзывов и обсуждений — для клиентского опыта и языка аудитории.
5. Социальные сети и пользовательский контент — для сигналов, но не для точных обобщений без проверки.
6. Поисковые сниппеты, агрегированные ответы и пересказы — только для обнаружения первоисточника.

Один источник может быть сильным для одного утверждения и слабым для другого.

## Внутренняя карточка утверждения

Для каждого существенного вывода зафиксировать:

| Поле | Содержание |
|---|---|
| Утверждение | Одна проверяемая мысль |
| Тип | факт / заявление / мнение / вывод / гипотеза |
| Источник | прямая ссылка |
| Независимость | первичный / независимый / пользовательский |
| Масштаб | единичный / повторяющийся / количественно измеренный |
| Актуальность | дата публикации или доступа |
| Противоречия | что не совпадает с другими источниками |
| Уверенность | высокая / средняя / низкая |
| Допустимая формулировка | как честно написать в брифе |

Не включать эту таблицу в итоговый бриф по умолчанию.

## Правила уверенности

- **Высокая:** прямой актуальный первичный источник для факта либо несколько независимых согласующихся источников.
- **Средняя:** косвенное подтверждение или повторяющийся клиентский сигнал при ограниченной выборке.
- **Низкая:** единичный сигнал, неполный источник или аналитическая гипотеза.

Не вычислять псевдоточную итоговую оценку.

## Отзывы

Не считать звездный рейтинг доказательством причины. Не смешивать разные филиалы, периоды, товары и типы клиентов. Не цитировать длинные фрагменты; передавать тему своими словами и давать короткий пример только при необходимости.

Клиентски подтвержденное преимущество требует повторяющегося положительного сигнала либо нескольких независимых конкретных свидетельств. Реальный дифференциатор дополнительно требует конкурентного сравнения.

## Целевая аудитория

Каждый сегмент должен опираться минимум на два разных типа сигналов, например:

- структура предложения + отзывы;
- кейсы + поисковое поведение;
- условия покупки + отраслевой источник;
- отзывы + сравнительные страницы конкурентов.

Если доступен только рекламный текст компании, маркировать портрет как гипотезу.

## Конфликты

При расхождении:

1. проверить даты, географию, филиал, продукт и условия;
2. предпочесть прямой и более актуальный источник для факта;
3. сохранить клиентский опыт как отдельный слой, даже если официальные правила иные;
4. явно описать противоречие, если оно влияет на выбор.

## Запрещенные преобразования

- отсутствие жалоб → доказанное преимущество;
- много отзывов → репрезентативность;
- высокая оценка → уникальность;
- характеристика → польза без объяснения механизма;
- польза → отличие без сравнения;
- совпадение → причинность;
- типичный покупатель категории → установленная аудитория компании;
- маркетинговое обещание → фактический результат.
