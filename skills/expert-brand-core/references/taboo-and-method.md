# Методология эксперта и реестр ТАБУ

Инструмент Этапа 3 для фиксации авторского метода работы и системы ТАБУ эксперта. Эти правила защищают блог от фальшивых обещаний, токсичных тем и шаблонов ChatGPT.

## 1. Распаковка авторского метода

Метод эксперта представляет собой воспроизводимую последовательность действий. Запрещено использовать абстрактные формулировки вроде «мой уникальный опыт».

### Схема фиксации метода:
1. **Название метода:** Короткое, отражающее суть (например, «Метод чистой воронки», «Архитектура личного ритма»).
2. **Шаги метода (3-5 этапов):**
   - Шаг 1: Диагностика / Аудит (где находим затыки).
   - Шаг 2: Расчистка / Устранение лишнего.
   - Шаг 3: Сборка ключевого механизма.
   - Шаг 4: Тест / Запуск.
   - Шаг 5: Закрепление / Автоматизация.
3. **Фирменные приемы и фреймы:** Названия конкретных шаблонов, таблиц, опросников или упражнений, которые эксперт дает клиентам.
4. **B2C vs B2B развилка:**
   - Для B2C: метод описывает личностную трансформацию клиента (от боли к результату).
   - Для B2B: метод описывает регламент операционного взаимодействия (как находим, согласуем, внедряем, отчитываемся).

## 2. Реестр ТАБУ (Критично для контент-генераторов)

ТАБУ — это сознательные ограничения эксперта. Именно они делают блог живым и выделяют его на фоне инфошума.

### Блок 1. Темы-ТАБУ (О чем эксперт никогда не пишет)
- Политика, чужие скандалы, хайп ради охватов?
- Темы смежных ниш, где эксперт не считает себя компетентным?
- Личная жизнь, семья, бытовые драмы (если эксперт держит жесткую грань приватности)?

### Блок 2. Обещания-ТАБУ (Что эксперт никогда не гарантирует)
- Запрет нереалистичных сроков («миллион за 3 дня», «похудей на 15 кг за неделю»).
- Запрет пассивных иллюзий («ничего не делай, деньги сами потекут»).
- Четкое разграничение ответственности: эксперт отвечает за методологию и инструменты, клиент — за действия и внедрение.

### Блок 3. Лексические ТАБУ (Стоп-слова)
- Инфоцыганские штампы: «секретный секрет», «уникальная авторская методика», «прорывной прорыв», «магический результат».
- Пустые связки: «в современном мире», «ни для кого не секрет», «давайте разберемся».
- Слова-паразиты, которые эксперт органически не переносит.

### Блок 4. Клиенты-ТАБУ (С кем эксперт не работает ни за какие деньги)
- Люди в позиции жертвы, ждущие волшебную таблетку.
- Токсичные или неэтичные ниши (ставки, пирамиды, микрозаймы).
- Клиенты без базовых предпосылок (например, если нет продукта или базового опыта).
