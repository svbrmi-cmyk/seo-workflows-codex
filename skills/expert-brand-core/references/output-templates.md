# Шаблоны артефактов для папки context/

Спецификация 5 файлов, которые скилл `expert-brand-core` записывает в папку `context/` рабочего пространства.

---

## 1. context/me.md — Паспорт эксперта

```markdown
# Экспертный профиль: [Имя Эксперта]

## 1. Главное позиционирование и Хай-концепт
- **Кто:** [Профессия / Экспертная роль]
- **Хай-концепт (High Concept):** [Неожиданное скрещивание двух доменов: «X через призму Y»]
- **Имя авторского метода:** [Звучное название технологии]
- **Главный конфликт с рынком:** [Против какого мифа/заблуждения восстает эксперт]
- **Фактор Голубого океана:** [Что создано нового по решетке УСКП, чего нет у конкурентов]
- **Ниша:** [Узкое определение ниши]
- **Для кого:** [Основной сегмент клиентов]
- **Ключевой результат:** [Главное обещание в измеримых терминах без обещаний-табу]
- **Психотип и Архетип:** [Психотип по тесту] · Архетип: [Эксперт / Мудрец / Бунтарь / ...]

## 2. Твердые факты и доказательная база
- **Опыт в теме:** [X] лет практики.
- **Главные цифры:** [Объем выручки клиентов, количество выпускников, решенные задачи].
- **Ключевые регалии:** [Образование, знаковые клиенты, публикации, выступления].
- **Формула авторитета:** [Почему клиенты платят именно этому человеку].

## 3. Флагманские кейсы (PDR)
### Кейс 1: [Клиент / Ниша]
- **Problem:** [С чем пришел, симптомы, ложные попытки].
- **Decision:** [Что сделали, какие инструменты применили].
- **Result:** [Твердые метрики + качественный сдвиг + цитата].

### Кейс 2: [Клиент / Ниша]
- **Problem:** ...
- **Decision:** ...
- **Result:** ...
```
