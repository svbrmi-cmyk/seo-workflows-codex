# Модель доказательств

## Статусы

| Статус | Когда применять | Пример |
|---|---|---|
| `Measured` | Наблюдение получено непосредственно из открытой страницы, ответа сервера, проверяемого инструмента или официального источника | canonical указывает на другой URL |
| `User-provided` | Данные или утверждение передал пользователь, включая экспорты закрытых систем | CTR из предоставленного CSV |
| `Estimated` | Аналитический вывод или вероятное объяснение, логически основанное на фактах | заголовок может снижать CTR |
| `Unknown` | Данных недостаточно или проверка недоступна | статус URL в индексе без консоли и операторов проверки |

Статус относится к конкретному утверждению, а не ко всему разделу. Данные инструмента могут быть `Measured`, но интерпретация причины остается `Estimated`.

## Минимальная запись наблюдения

Для каждого существенного пункта указать:

- наблюдение;
- локатор: URL, элемент, селектор, заголовок, строка экспорта или период;
- источник и дату;
- статус доказательства;
- уверенность: высокая, средняя или низкая;
- канал: Google, Яндекс, AI-поиск, несколько;
- ожидаемое влияние без числовой гарантии;
- проверяемое исправление.

## Причинность

Не писать «X вызвал падение», если наблюдалась только корреляция. Для сильного причинного вывода требовать временную последовательность, правдоподобный механизм, исключение значимых альтернатив и по возможности контроль/сравнение. Иначе использовать формулировки «совпало», «может объяснять», «гипотеза для проверки».

## Источники

Приоритет: официальная документация и первичные данные → непосредственно наблюдаемая страница/ответ → предоставленные экспорты → независимые надежные исследования → инструментальные оценки → модельный вывод.

Повторяющиеся пересказы одного первоисточника не считать независимыми подтверждениями. Для изменчивых правил указывать дату и ссылаться на актуальную официальную документацию.

## Запреты

- Не выдумывать частотность, трафик, позиции, CTR, долю AI-ответов и причины изменений.
- Не считать отсутствие данных отрицательным результатом.
- Не представлять выборочную SERP как универсальную для всех регионов и пользователей.
- Не выдавать тест одного AI-движка за наблюдение во всех AI-системах.
