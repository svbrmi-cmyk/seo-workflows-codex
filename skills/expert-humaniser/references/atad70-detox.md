# База детокса нейротекста (ATAD-70)

Реестр 70 маркеров ИИ-письма, канцелярита и штампов. Используется на этапе **DETECTOR** для выявления нейросетевых дефектов и на этапе **REWRITER** для их чистки.

---

## Группа A. Лексические ИИ-сигнатуры (Слова-маркеры)
*(Заменять на простые разговорные аналоги или вырезать)*

1. **Погрузимся / Давай погрузимся** → Разберем, посмотрим, напишем, (вырезать)
2. **Экосистема** → Система, набор, платформа, чаты
3. **Ключевые аспекты / Ключевые моменты** → Главное, суть, факты
4. **Трансформационный / Трансформирует** → Изменил, переработал, улучшил
5. **Важно понимать / Важно отметить** → (вырезать зачин, сразу мысль)
6. **В современном мире / В эпоху [X]** → Сегодня, сейчас, (вырезать)
7. **Широкий спектр / Многообразие** → Набор, разные
8. **Бесшовный / Seamless** → Гладкий, простой, без сбоев
9. **Эффективный / Эффективность** → Дает [конкретный результат]
10. **Инновационный** → Новый, свежий
11. **Уникальный** → Редкий, особенный, (показать в чем суть)
12. **Фундаментальный** → Базовый, основной
13. **Оптимизация / Оптимизировать** → Улучшить, ускорить, срезать косты
14. **Синергия** → Совместная работа, связка
15. **Масштабируемый** → Растущий, гибкий

## Группа B. Конструкционные зачины и паразиты (Throat-Clearing)
*(Удалять полностью, начинать сразу со сути)*

16. *"В этой статье/посте мы разберем..."* → (Сразу к сути)
17. *"Ни для кого не секрет, что..."* → (Удалить)
18. *"Как мы все знаем..."* → (Удалить)
19. *"Не секрет, что в 2026 году..."* → (Удалить)
20. *"Давайте честно / Будем откровенны..."* → (Удалить)
21. *"Прежде чем начать, стоит сказать..."* → (Удалить)
22. *"Подводя итог вышесказанному..."* → Итого:, В итоге:
23. *"Сложилось впечатление, что..."* → Кажется, что...
24. *"Нельзя не упомянуть..."* → И еще:
25. *"В контексте данного вопроса..."* → Здесь...
26. *"С точки зрения [X]..."* → По мнению [X]...
27. *"Исходя из вышесказанного..."* → Поэтому...
28. *"Таким образом, мы видим..."* → И вот результат:
29. *"Стоит обратить внимание на..."* → Посмотрите на...
30. *"В завершение хочется сказать..."* → (Сразу финальная мысль)

## Группа C. AI Staccato & Рубленый псевдо-драматизм
*(Связывать в естественные предложения)*

31. **Контрастный обрыв:** *"Он искал клиентов. Год. Два. Без результата."* → *"Он искал клиентов два года без результата."*
32. **Искусственный финал:** *"Два расследования. Один город. Никто не знал."* → *"Два параллельных расследования в одном городе не знали друг о друге."*
33. **Однословный драматический абзац:** *"Боль."* / *"Шок."* / *"Точка."* → Вплетать в контекст предложения.
34. **Трио вопросов:** *"Как? Зачем? Почему?"* → Задавать 1 конкретный смысловой вопрос.
35. **Тройные прилагательные:** *"Быстрый, надежный, эффективный способ"* → Оставлять 1 точный факт.
36. **Эхо-повтор:** *"Это было трудно. Действительно трудно."* → Называть конкретную причину сложности.
37. **Нагнетание капсом/двоеточием:** *"Главный вывод: ВСЁ ИЗМЕНИЛОСЬ."* → Писать нормальным предложением.
38. **Театральная пауза:** *"И тогда он понял... Всё было зря."* → *"Оказалось, подходы не работали."*
39. **Псевдо-диалог:** *"Звучит круто? Да. Но есть нюанс."* → *"Схема выглядит рабочей, пока не упирается в ограничение."*
40. **Навязчивое вовлечение:** *"Согласны? Напишите в комментариях!"* → Нативный или предметный вопрос.

## Группа D. Драматургические клише и TED-Talk пафос
*(Заменять конкретными фактами или вырезать)*

41. *"Не просто X, а Y"* → *"Увеличивает вовлеченность на 40%"*
42. *"Это не просто бот, это философия"* → Показать конкретный результат бота.
43. *"Геймчейнджер / Переворот игры"* → *"Решает проблему X за Y минут"*
44. *"Настоящий прорыв в индустрии"* → Показать факты без оценочности.
45. *"Все изменилось навсегда"* → Сформулировать точное изменение.
46. *"Это поворотный момент"* → Описать событие.
47. *"Новый уровень мышления"* → Указать методику.
48. *"Высшая точка мастерства"* → Описать кейс.
49. *"Мощный импульс для роста"* → Привести цифры роста.
50. *"Раскрывает потенциал"* → Дает возможность [конкретное действие].
51. *"Глубокий инсайт"* → Вывод, наблюдение.
52. *"Ключ к успеху"* → Инструкция, правило.
53. *"Магия происходит тогда, когда..."* → Механика работает так:
54. *"Главный секрет прост..."* → Суть метода:
55. *"Приготовьтесь удивляться"* → (Удалить)

## Группа E. Синтаксические и Инфостилевые дефекты
*(Упрощать конструкцию)*

56. Нагромождение отглагольных существительных (*«для осуществления процесса оптимизации вовлечения»*) → *"чтобы вовлекать участников"*
57. Пассивный залог (*«Было принято решение о запуске»*) → *"Мы запустили"*
58. Раздутые предложные группы (*«в связи с тем фактом, что»*) → *"потому что"*
59. Оценка вместо фактов (*«очень качественный продукт»*) → *"конверсия 18%"*
60. Обезличенные местоимения (*«некоторые эксперты считают»*) → Ссылка на автора или себя
61. Двойные отрицания (*«нельзя не согласиться»*) → *"согласен"*
62. Канцелярские глаголы (*«является», «осуществляет», «производит»*) → Простые глаголы действия
63. Сверх-обобщения (*«каждый из нас сталкивался»*) → *"многие владельцы клубов сталкиваются"*
64. Модальные раздутия (*«имеет возможность позволить себе»*) → *"может"*
65. Замена разговорных слов книжными (*«функционирует»*) → *"работает"*
66. Кавычки для защиты от смысла (*«так называемый»*) → Называть своим именем без кавычек
67. Списки из 10 неочевидных пунктов без иерархии → Списки из 3–5 главных пунктов
68. Вводные междометия в начале (*«Итак,»*, *«Итак, друзья,»*) → Сразу мысль
69. Хештеги в середине текста → Нативные ключевые слова
70. Пустой дежурный финал (*«Надеюсь, пост был полезен!»*) → Вопрос по теме или призыв к обсуждению.
