# Поиск через Perplexity

Использовать `scripts/perplexity_search.py` как первый этап интернет-исследования. Скрипт обращается к официальному Sonar API и не выводит API-ключ.

## Порядок работы

1. Проверить наличие переменной окружения `PERPLEXITY_API_KEY`:

   ```powershell
   if ($env:PERPLEXITY_API_KEY) { 'present' } else { 'missing' }
   ```

2. Составить список отдельных исследовательских задач. Выполнять их строго
   последовательно: один активный вызов Perplexity API за раз. Не запускать запросы
   параллельно и не создавать всплеск обращений.

3. Каждый успешный результат сразу сохранять в отдельный JSON- или Markdown-файл.
   Перед следующим вызовом проверять, что файл создан и не пуст. Это позволяет
   продолжить исследование с первой непокрытой задачи после сбоя или смены ключа.

4. Запустить запрос для текущей исследовательской задачи:

   ```powershell
   python scripts/perplexity_search.py "точный исследовательский запрос"
   ```

5. Для более глубокого исследования выбрать модель явно:

   ```powershell
   python scripts/perplexity_search.py "запрос" --model sonar-deep-research
   ```

6. При необходимости ограничить источники доменами, языком или периодом:

   ```powershell
   python scripts/perplexity_search.py "запрос" --domain example.com --language ru --recency month
   ```

7. Для машинной обработки запросить JSON или сохранить результат:

   ```powershell
   python scripts/perplexity_search.py "запрос" --format json --output result.json
   python scripts/perplexity_search.py "запрос" --output result.md
   ```

8. Извлечь URLs из разделов `Источники` и `Поисковые результаты`. Открыть значимые страницы напрямую и проверить утверждения по первичным источникам.

## Работа с API-ключом

- Сначала использовать `PERPLEXITY_API_KEY` из окружения, проверяя только наличие,
  но не печатая значение.
- Если пользователь передал ключ в чате, применять его только через окружение
  конкретного процесса вызова API. Не повторять ключ в сообщениях и подтверждениях.
- Не помещать ключ в аргументы командной строки, stdout, stderr, журналы, отчеты,
  результаты поиска и создаваемые артефакты.
- Не записывать ключ в `.env`, конфигурацию, скрипты, skill-файлы или постоянные
  переменные среды без отдельного прямого указания пользователя.

## Доказательный стандарт

- Использовать Perplexity для обнаружения источников, терминов, конкурентов и противоречий.
- Не считать сгенерированный ответ самостоятельным доказательством.
- Для фактов о компании, продукте, цене, законе или спецификации открывать официальный источник.
- Не считать поисковый сниппет подтверждением содержания всей страницы.
- Отделять ответ модели от массива `citations` и сырых `search_results`.
- При отсутствии URL, пустом ответе или нерелевантных результатах уточнить запрос либо перейти к резервному поиску.
- Не раскрывать и не сохранять `PERPLEXITY_API_KEY`; соблюдать раздел «Работа с API-ключом».

## Ошибки

- `PERPLEXITY_API_KEY is not set`: сообщить о недостающей переменной окружения.
- HTTP 401/403: считать текущий ключ недействительным или не имеющим доступа и не
  повторять с ним запрос.
- HTTP 429: остановить новые вызовы, не запускать автоматический цикл повторов и не
  дублировать весь список задач. Проверить уже сохраненные файлы. После снятия лимита
  или получения другого действующего ключа продолжить последовательно с первой
  непокрытой задачи.
- HTTP 5xx или сетевая ошибка: повторить один раз; затем зафиксировать сбой и использовать разрешённый резервный поиск.
- Пустые `citations`: использовать найденный ответ только как ориентир и отдельно искать первоисточники.

## Поддерживаемые параметры

Получить актуальную справку:

```powershell
python scripts/perplexity_search.py --help
```

По умолчанию используются модель `sonar-pro`, endpoint `https://api.perplexity.ai/v1/sonar`, русский язык ответа и Markdown-вывод.
