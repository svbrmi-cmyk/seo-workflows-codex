## 3. Wordstat и границы интента

- Параметры: последние 30 дней, регион, устройства, дата проверки.
- Проверенные seed-фразы: фраза, `totalCount`, релевантные строки топа.
- Отклонённый шум: кратко назвать чужой интент без полного сырого ответа.
- Вывод для обложки: язык аудитории, допустимая короткая надпись и запрещённые смысловые направления.
- Локальный файл доказательств: путь внутри `D:\CODEX\outputs`.
- Локальный Markdown с запросами: путь внутри `D:\CODEX\seo-workflows-codex\texts`.
