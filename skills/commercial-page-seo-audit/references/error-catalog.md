# Каталог ошибок, найденных в коммерческих текстах

Проверяй текст по этому списку. Он пополняется по мере работы с новыми страницами.

## Технические и терминологические

| Ошибка в тексте | Как на самом деле |
|---|---|
| Класс КМ (КМ2, КМ3) связывают с теплопроводностью или «термосопротивлением» | КМ — класс пожарной опасности, к теплу не относится |
| «КМ3 для жилых зон» | Для квартир в РФ класс КМ не нормируется, его требуют в общественных зданиях и на путях эвакуации |
| КМ2/КМ3 для салонов автобусов и машин | Для транспорта действуют свои требования к горючести, не строительные классы КМ |
| EN 1815 — «термическая стабильность» | EN 1815 — испытание на статическое электричество |
| ActionBac — «джутовая основа» | ActionBac — синтетическая (полипропиленовая) вторичная основа |
| dtex — «плотность стежков» | dtex — линейная плотность (толщина) нити |
| Цвета ковролина «по RAL» | RAL — палитра красок, ковролин по ней не маркируют |
| Полипропилен «не выгорает на солнце» | Полипропилен плохо переносит ультрафиолет |
| Иглопробивное полотно описано как тафтинговое или с «петлями ворса» | Иглопробивное полотно нетканое, без петель и тафтинга |
| «Резиновый ход» | Такого термина нет. Правильно: латексная основа, вспененный латекс, прорезиненный ковролин |
| «Температура основания не выше 27 °C» | 27 °C — обычный предел температуры поверхности пола в жилых помещениях |
| «Резиновая основа защищает кузов от коррозии» | Коррозию вызывает влага, застаивающаяся под покрытием |
| «Полые волокна шерсти» | Волокно шерсти не полое |
| Натуральные волокна (сизаль, джут, хлопок) — «проводники тепла» | Натуральные волокна — изоляторы. Тонкие циновки подходят на подогрев из-за малой толщины |
| Толстая вспененная резина «подходит для тёплого пола» | Толстая вспененная основа работает как утеплитель |
| «Перегрев труб» водяного пола | Перегрев грозит кабелю и плёнке, водяной контур работает с перегрузкой |
| Мощность радиатора из каталога считают реальной для любой системы | Паспортная мощность дана при Δt 70 °C (95/85/20). При графике 80/60 отдача ниже примерно в 1,5 раза, при 70/55 — почти вдвое |
| «Двухтрубный радиатор» без пояснения | У трубчатых радиаторов это число рядов трубок в глубину, не путать с двухтрубной системой отопления |
| «Длинный радиатор» только как горизонтальный | В выдаче Яндекса «длинные радиаторы» — это и длинные горизонтальные, и высокие вертикальные модели |

## Неподтверждённые утверждения (проверять по сайту)

- шоурум, выставочный зал, склад, «складская программа»;
- доставка в регионы и конкретные города;
- бесплатный расчёт, бесплатная доставка от суммы, бесплатный выезд;
- график работы (пн–пт), способы оплаты, оплата картой курьеру, возврат;
- акции, распродажи, новинки;
- конкретные цвета, ширины рулонов, страны производства, классы у моделей;
- бренды, которых нет в ассортименте категории (ковры, IDEAL на резине и т. п.).

## Выдуманные цифры и абсолюты

- «на 50% зависит от укладки», «снижает эффективность на 20%», «ресурс сокращается в несколько раз»;
- «вес ворса 1310 г/м²» и «2,3 кг/м²» в одном тексте;
- «от −40 °C до +60 °C», «инертны к бензину и антифризу»;
- «не выделяет формальдегидов», «у всех наших покрытий антистатическая защита», «не теряет форму за весь срок»;
- «лидеры мировой индустрии», «проверенные временем инженерные решения», «без удорожания».

## Внутренние противоречия

- ширина рулонов в разных абзацах разная;
- одна линейка под разными названиями (iDEAL Grass / IDEAL Erba);
- «одинаковый класс применения, но для зон с разной проходимостью»;
- «самая износостойкая» у двух разных видов;
- иглопробивное полотно и «тактильный уют для спальни»;
- «не скользит» при исходной оговорке «зависит от модели и фиксации»;
- «можно класть свободно» при исходном «без фиксации пойдёт волнами»;
- ассортимент категории не совпадает с текстом (интерьерные модели в разделе «ковролин в машину»).

## Грамматика

- согласование: «покрытие… рассчитан», «покупка… требуют», «стоимость… рассчитываются»;
- склейки и опечатки: «покрытияпод», «ниями», «воокон», «в общем смете»;
- «двухсторонний» → «двусторонний», «проступей» → «ступеней»;
- лишние запятые перед сказуемым.
