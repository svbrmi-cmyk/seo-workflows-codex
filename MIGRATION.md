# Consolidation

The reusable skills formerly stored in `svbrmi-cmyk/codex-workspace` and
`svbrmi-cmyk/chat-gpt-work` are maintained only in this repository.

- 22 unique skill names; each has one folder under `skills/`.
- The SEO version of `analyze-content-platform` is the primary workflow.
  The complementary research matrix and business-value guidance from
  `chat-gpt-work` are retained in that folder.
- The `platform-content-strategy` version from `newclone` is retained.
  The older backup variant remains available in the source repository history.
- `analyze-text-wordstat-semantics` differed locally only in line endings.
- The canonical `use-grsai-text` wording follows the existing SEO library.
- Extra frontmatter fields in five imported skills were preserved under `metadata`.
- ZIP exports, Python caches and repeated skill folders are not maintained.
- Existing system skills and installed third-party plugin runtimes are managed
  separately; they are not copied into this user-maintained library.
- `svbrmi-cmyk/seo-workflows-content-automation` is outside this migration.

Source snapshots:
- seo-workflows-codex: 59ecc79e8173a42a5a8bb0add3675349e04e6b41
- codex-workspace: be43c290c62fbf9c4ce50e229c929469c59049a0
- chat-gpt-work: 72914707b21c66a1199ba51b7cbbb04f14bf5f1d

The migration preserves skill instructions, their required references, scripts,
metadata and existing license files. Working articles, customer inputs, workflow
credentials and task outputs are not part of this library.
