# Таблицы анализатора

## Роли и заголовки

### LSI-слова

Обычно используются листы `Сводим формы слов` и `Все формы слов`.

Распознавать:

- группа: `Слово`, `Слова`;
- медиана: `Медиана`;
- текущая частота: `Текст у вас`, `Ваша страница`,
  `Ваша страница (повторы)`;
- связь: `Связь слов с другим листом`;
- часть речи: `Часть речи`.

На сводном листе связь идентифицирует группу. На листе всех форм последняя связь
указывает, к какой группе относится словоформа.

Для семантической ширины сохранять исходный порядок сводного листа и брать первые
150 разных групп после заголовка, если пользователь не указал другое число в
диапазоне 140–150. Не отбрасывать строку из пула ширины только потому, что ее
медиана равна нулю или пуста. Положительную медиану использовать для глубины и
лимита повторов; нулевую или пустую — только для однократного релевантного
`breadth-only exception`.

### N-граммы

Распознавать:

- фраза: `N-граммы`, `N-граммы (включая все словоформы)`;
- медиана: `Медианное вхождение`;
- текущая частота: `На нашем сайте`.

N-граммы не являются отдельным словарем для механического заполнения. Сначала
исключать юридические, интерфейсные, чужие товарные и шаблонные фразы. Оставшиеся
использовать как образцы сочетаний в пределах медиан отдельных LSI-групп.

### Глубина

Распознавать:

- `Слово`;
- `Словоформы`;
- `Повторы`;
- `Минимум по рекомендациям`;
- `Максимум по рекомендациям`;
- `Добавить/Удалить`;
- `Текст у вас`;
- `Текст рекомендации`;
- `Текст Добавить/Удалить`.

Отрицательное общее `Добавить/Удалить` маркирует группу на сокращение. Отрицательное
`Текст Добавить/Удалить` само по себе не маркирует вспомогательное слово.

## Нормализация заголовков

Перед сопоставлением:

1. привести к нижнему регистру;
2. заменить символ `U+0451` на `е`;
3. схлопнуть пробелы и переносы;
4. убрать внешние пробелы;
5. разрешить уточнение в скобках после основного названия.

Не путать:

- `Медиана` с минимумом, максимумом, средним, TF-IDF или BM25;
- общий `Добавить/Удалить` с `Текст Добавить/Удалить`;
- `Повторы` всей страницы с частотой только текстовой зоны.

## Файл нерелевантных слов

Если указана только словоформа:

- не добавлять ее;
- стремиться к нулю, если удаление не меняет факт.

Если рядом указано число, считать его целевым остатком. Считать точные словоформы и
дополнительно проверять очевидные формы той же леммы.

## Конфликты

Не объединять цели разных итераций. Признаки несинхронности:

- собственный исходный подсчет отличается от `Повторы` или `Ваша страница`;
- одинаковая группа имеет разные медианы в двух LSI-файлах;
- отрицательная квота рассчитана для текста, который уже изменен;
- `Повторы + Добавить/Удалить` не равно рекомендованному максимуму.

При несинхронности использовать фактический текст для редактирования, явно пометить
расчет как предварительный и запросить повторный анализ результата.
