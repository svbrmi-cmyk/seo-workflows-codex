# Форматы входных таблиц и списков

## LSI

Обычно используются листы `Сводим формы слов` и `Все формы слов`.

Распознавать:

- основная группа: `Слово`, `Слова`;
- глубина: `Медиана`;
- текущая частота: `Текст у вас`, `Ваша страница`,
  `Ваша страница (повторы)`;
- идентификатор: `Связь слов с другим листом`;
- справочное поле: `Часть речи`.

На сводном листе сохранять исходный порядок. Брать первые 150 разных основных
групп после заголовка, если пользователь не задал 140–149.

По идентификатору собирать словоформы со второго листа. Основное слово также
включать в группу. Строку с нулевой или пустой медианой не исключать из ширины.

- положительная медиана: цель глубины и предел новых повторов;
- нулевая или пустая: максимум одно новое релевантное употребление для ширины.

## Глубина

Распознавать:

- `Слово`;
- `Словоформы`, `Словоформа`;
- `Повторы`, `Текст у вас`;
- `Минимум по рекомендациям`;
- `Максимум по рекомендациям`;
- общий `Добавить/Удалить`;
- справочные `Текст рекомендации`, `Текст Добавить/Удалить`.

Достаточно столбцов слова, словоформ и хотя бы одного числового показателя.

Правила:

- общий отрицательный `Добавить/Удалить` задает квоту сокращения;
- превышенный `Максимум по рекомендациям` также задает сокращение;
- `Минимум по рекомендациям` является желательным нижним ориентиром только для
  релевантного слова;
- отрицательный `Текст Добавить/Удалить` сам по себе не маркирует группу на
  сокращение, потому что относится к отдельной зоне страницы.

Не вставлять шум ради выполнения минимума.

## N-граммы

Распознавать:

- `N-граммы`, `N-граммы (включая все словоформы)`;
- `Медианное вхождение`;
- `На нашем сайте`.

N-грамма является вторичным образцом формулировки. Ее медиана не отменяет пределы
отдельных слов и не требует механического заполнения.

## Точные нерелевантные слова

Поддерживаемый формат анализатора:

```text
Нерелевантное слово (точная словоформа) заранее у вас повторяется 2 раз(а)
```

Здесь:

- `заранее` — точная проверяемая форма;
- `2` — текущее количество в анализаторе;
- целевой остаток по умолчанию — `0`.

Не считать число после `повторяется` целевым остатком.

Поддерживается и простой список через запятую, точку с запятой или перенос строки.
Для обоснованного минимального остатка агент может подготовить нормализованный
контрольный файл:

```text
точная форма -> 1
другая форма -> 0
```

Число после стрелки является явной целью. Оно не связано с фразой анализатора
`у вас повторяется N раз`.

Считать точную словоформу, а не автоматически всю лемму. Очевидные родственные
формы проверять отдельно вручную.

## Дополнительный список ширины

Поддерживать список через запятую, точку с запятой или перенос строки.

Для каждого элемента:

1. проверить релевантность и наличие исходного факта;
2. проверить, не входит ли он в LSI-группу;
3. использовать свободный остаток положительной медианы либо одно употребление
   ширины;
4. пропустить служебный, юридический и чужой элемент.

Список ширины может содержать намеренно смешанные подходящие и неподходящие слова.
Нельзя вставлять его целиком автоматически.

## Список релевантных групп

Для точной отфильтрованной метрики подготовить файл основных названий LSI-групп
через запятую или перенос строки. Включать только:

- релевантные;
- условно релевантные в подтвержденном контексте;
- неизменяемые сущности, реально присутствующие в теме.

Валидатор сопоставляет этот файл с основными группами первых 140–150 строк и
выводит `filtered_width` и `filtered_depth`. Несопоставленное название становится
предупреждением.

## Нормализация

Перед сопоставлением:

1. привести к нижнему регистру;
2. заменить `U+0451` на `е`;
3. схлопнуть пробелы и переносы;
4. убрать внешние пробелы;
5. разрешить уточнение заголовка в скобках.

Не путать:

- `Медиана` с минимумом, максимумом, средним, TF-IDF или BM25;
- общий `Добавить/Удалить` с `Текст Добавить/Удалить`;
- `Повторы` всей страницы с частотой отдельной текстовой зоны;
- текущее число в файле нерелевантных слов с целевым остатком.

## Несинхронные итерации

Признаки:

- собственный подсчет отличается от `Повторы` или `Ваша страница`;
- одинаковая группа имеет разные медианы в двух LSI-файлах;
- квота рассчитана для уже измененного текста;
- `Повторы + Добавить/Удалить` не совпадает с максимумом;
- файл нерелевантных слов сообщает другое текущее количество.

При несинхронности редактировать фактический текст, пометить расчет как
предварительный и рекомендовать повторный анализ результата.
