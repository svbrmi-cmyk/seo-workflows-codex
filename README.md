# Reusable Codex skills

Single source of truth for 22 user-maintained skills: SEO, research, content,
Pragmatix editorial workflows, product catalogs and the Polmix workflow.

The former copies from codex-workspace and chat-gpt-work are consolidated here.
System skills and installed third-party plugins remain managed separately.
See [migration notes](MIGRATION.md) for version choices and provenance.

## Local setup

Keep the repository at D:\CODEX\seo-workflows-codex. Install local links with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-local.ps1
```

Existing user skill folders are backed up on D: before links are created.
An existing GRS plugin supplies use-grsai-text without another discovery entry.
Newly installed skills become available on the next Codex turn.

## Validation

```powershell
python -m pip install -r requirements-dev.txt
python -X utf8 scripts/validate-skills.py
```

Validation checks metadata, local Markdown links, YAML and Python syntax.
It does not execute external API requests, generate content or run n8n workflows.

## Runtime requirements

- perplexity-search and the research workflows need Python and Perplexity access.
- analyze-text-wordstat-semantics needs PowerShell and authorized Wordstat access.
- create-seo-text-client-brief needs Playwright and connected Google Docs/Drive.
- use-grsai-text needs the installed GRS AI plugin and its MCP tool.
- polmix-content-workflow operates the separately installed Polmix n8n kit.
- Read each skill for its exact inputs and dependencies. Never commit secrets.
